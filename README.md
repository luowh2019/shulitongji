# 数理统计工具箱（安卓 App）

一个离线可用的常用数理统计快速计算与可视化安卓工具：WebView 壳 + 单文件 H5 + Canvas 绘图。

## 功能
- 正态分布（高斯）：调 μ/σ，PDF 曲线，μ±1/2/3σ 覆盖概率
- 学生 t 分布：自由度可调，与正态对比，t 临界值
- 卡方分布：自由度可调 PDF，均值/方差/分位数
- 参数估计：样本均值、标准差、t 置信区间
- 贝叶斯：Beta-Binomial 先验→后验更新
- 蒙特卡洛：正态抽样直方图 + 理论曲线叠加
- 马尔可夫链：2 状态转移矩阵，状态演化与稳态
- 威尔逊区间：比例置信区间
- 杜安模型：试验前规划/反算/反推 α
- 克罗-阿姆萨模型：定时/定数截尾分析、置信区间、克罗扩展投影

## 编译
GitHub Actions 自动编译：push 到 main 后，Actions 产物 `shulitongji-apk` 即为 debug APK。
本地无需 Android SDK，云端用 JDK17 + Gradle 8.4 + AGP 8.1.4。
