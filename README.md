# 数理统计工具箱（安卓 App）

一个离线可用的常用数理统计快速计算与可视化安卓工具。
技术栈：**WebView 壳 + 单文件 H5 + Canvas 2D 绘图**，不依赖任何外部库，数学函数自实现（Lanczos lgamma、Acklam 正态分位数、Wilson-Hilferty 卡方分位数、Box-Muller 正态抽样等）。

## 功能一览

首页两列导航：左列「分布与统计」，右列「区间与可靠性」。

### 分布与统计

| 功能 | 说明 |
|---|---|
| 正态分布 N(μ,σ²) | 调 μ/σ，PDF 曲线 + 标准正态 N(0,1) 灰色参照线；显示 μ±1σ/2σ/3σ 覆盖概率 |
| t 分布 | 自由度可调，与标准正态对比；显示双侧 95% 临界值 |
| 卡方分布 χ²(ν) | 自由度可调，灰色为同均值同方差正态 N(ν, √(2ν)) 参照；显示均值/方差/95% 双侧分位 |
| F 分布 F(d₁,d₂) | 分子/分母自由度可调，灰色为同均值同方差正态参照；显示均值/标准差 |
| 参数估计 | 输入样本数据，自动算均值、标准差、95% t 置信区间 |
| 贝叶斯统计 | Beta-Binomial 先验→后验更新；先验 α/β、成功 k、试验 n 可调；带输入合法性校验（k≤n） |
| 蒙特卡洛模拟 | 正态抽样直方图 + 理论 PDF 叠加；抽样次数、μ、σ 可调 |
| 马尔可夫链 | 2 状态转移矩阵，状态演化曲线与稳态分布；概率 0~1、行和=1 校验 |

### 区间与可靠性

| 功能 | 说明 |
|---|---|
| 威尔逊区间 | ① 样本量估算（半宽对照表）② 命中比例区间（m/n 比例的置信区间） |
| 杜安模型 | 试验前规划（M₀/T₀/α/M_g）、给定试验时间反算 MTBF、两点反推增长率 α |
| 克罗-阿姆萨模型 | 定时/定数截尾失效数据分析（N、β、α、瞬时 MTBF、置信区间）、达标时间预测、克罗扩展模型投影 |

## 设计特点

- **离线**：所有计算和绘图都在本地 H5 内完成，无网络请求
- **自适应坐标轴**：函数最大值扫描 + 固定 y 轴刻度网格，避免曲线越界
- **参照对比**：正态/t/卡方/F 均叠加灰色正态参照线，参数变化一目了然
- **输入校验**：σ>0、自由度≥1、概率 0~1、马尔可夫行和=1、贝叶斯 k≤n 等越界即报错，且步进按钮自动禁用
- **移动端优先**：单栏卡片布局，适配手机竖屏

## 编译

GitHub Actions 自动编译：push 到 `main` 后，Actions 产物 **`shulitongji-apk`** 即为 debug APK，下载后安装即可。

- 本地无需 Android SDK
- 云端环境：JDK 17 + Gradle 8.4 + AGP 8.1.4，compileSdk 34 / minSdk 21
- 工作流：`.github/workflows/build-apk.yml`
